# note 記事 自動生成機能 セットアップガイド

この Laravel アプリには、note(note.com) 向けの長文記事を Claude で自動生成し、ダッシュボードで下書き管理する機能が含まれています。

## できること

- Claude API でジャンルに沿った note 記事(約2500字、調整可)を自動生成
- ダッシュボード上で記事の編集・タグ付け
- 本文をワンクリックでクリップボードにコピー → note の編集画面に貼り付けて公開
- 「公開済み」マーク管理(自分の管理用、note 側への投稿はされません)

## できないこと

- **note への自動投稿はできません。** note には公式の投稿 API が無く、非公式 API は利用規約違反 + 仕様変更で壊れるため実装していません。
- 公開ボタンを押した瞬間に note に投稿される、ということはありません。本文コピー → note の編集画面に貼って公開、という半自動フローになります。

## 1. データベースの準備

```
php artisan migrate
```

`note_articles` テーブルが追加で作成されます。

## 2. Anthropic API キーの設定

X / Threads 機能と共通です。

```
ANTHROPIC_API_KEY=...
ANTHROPIC_MODEL=claude-opus-4-7
```

## 3. note 関連の設定(任意)

`.env` で記事のジャンルと長さの目安を変更できます。デフォルトはプログラミング・技術 / 約2500字です。

```
NOTE_CONTENT_GENRE=プログラミング・技術
NOTE_TARGET_CHARS=2500
```

設定変更後は `php artisan config:clear` を実行してください。

## 4. 使い方

- ログイン後、`/note` にアクセスするとダッシュボードが開きます。
- 「テーマ」を空欄にすると、ジャンルから Claude が自動でテーマを選定します。
- 1本あたり30秒〜1分ほど生成にかかります。
- 生成された下書きは画面上で直接編集できます。
- 「本文をコピー」→ <https://note.com/> の新規記事編集画面に貼り付け → タイトルとタグを設定 → 公開。
- 公開し終えたらダッシュボード側で「公開済みにする」を押せば管理側のステータスが更新されます。

## コマンドラインから生成

```
php artisan note:generate-articles 1
php artisan note:generate-articles 2 --topic="PHPの型システムが提供する3つの安心"
```
